O que é

Conhecimento de n8n empacotado como skill

Cada skill é uma pasta com um SKILL.md e arquivos de referência. O Claude Code lê a descrição, decide sozinho quando o assunto é aquele, e só então puxa o detalhe que precisa — o contexto fica leve.

🎯 Dispara sozinha

Você não invoca nada à mão. Falou em webhook, expressão {{ }} ou erro de validação, a skill certa entra.

📚 Carregamento em camadas

O SKILL.md é curto; catálogos de erro, padrões e referências de API só entram no contexto quando o caso pede.

🔌 Casa com o MCP n8n-mcp

Com o servidor n8n-mcp conectado, dá pra buscar nodes, validar config e publicar workflow. Sem ele, as outras seis seguem valendo.

Como funciona

Do desenho ao workflow publicado

A ordem em que as skills entram numa construção típica. O laço entre validar e corrigir costuma dar 2–3 voltas — é o normal, não é sinal de que algo deu errado.

Desenhar→ Configurar nodes→ Expressões & Code→ Validar→ Corrigir↺ Publicar via MCP
1

Arquitetura

n8n-workflow-patterns escolhe o padrão: webhook, API HTTP, banco, AI agent ou agendado.

2

Construção

node-configuration, expression-syntax e os dois code-* preenchem os nodes.

3

Fechamento

validation-expert lê os erros; mcp-tools-expert valida e publica no n8n.

As 7 skills

O que cada uma cobre

Todas ficam em skills/ no repositório, com symlinks em .claude/skills/ — que é de onde o Claude Code carrega.

🧩 n8n-workflow-patterns

Os cinco padrões arquiteturais comprovados: processamento de webhook, integração HTTP/API, operações de banco, workflow de AI agent e tarefas agendadas.

Dispara ao desenhar ou estruturar um workflow novo.

⚙️ n8n-node-configuration

Configuração ciente da operação: campos obrigatórios, dependências entre propriedades e qual nível de detalhe pedir no get_node.

Dispara ao configurar um node específico.

🔤 n8n-expression-syntax

Sintaxe {{ }}, variáveis $json e $node, dados vindos de webhook e o catálogo de erros clássicos.

Dispara ao escrever ou corrigir expressões.

🟨 n8n-code-javascript

Code node em JavaScript: $input/$json/$node, $helpers.httpRequest, datas com DateTime e a escolha entre os modos do node.

O caminho recomendado para ~95% dos casos.

🐍 n8n-code-python

Code node em Python (beta): _input/_json, o que dá pra usar da biblioteca padrão e as limitações reais frente ao JS.

Só quando Python for mesmo necessário.

✅ n8n-validation-expert

Interpretar e resolver erros de validação: catálogo de erros, perfis de validação, estrutura de operadores e como reconhecer falsos positivos.

Dispara quando um validate_* reclama.

🛠️ n8n-mcp-tools-expert

Uso eficiente das ferramentas do MCP n8n-mcp: descoberta de nodes, validação de configuração, gestão de workflows e a biblioteca de ~2.700 templates reais.

Requer o servidor n8n-mcp conectado.

📁 Como estão organizadas

Uma pasta por skill, com SKILL.md mais os anexos: ERROR_CATALOG.md, COMMON_PATTERNS.md, DATA_ACCESS.md, FALSE_POSITIVES.md, DEPENDENCIES.md e afins.

Pré-requisitos

O que você precisa antes de começar

O básico é só o Claude Code e o repositório clonado. O MCP e a instância n8n são opcionais — sem eles você perde a publicação automática, não o conhecimento.

Claude Code

As skills usam o mecanismo nativo de skills de projeto (.claude/skills/).

# versão instalada
claude --version

O repositório

Clone e abra o Claude Code de dentro da pasta — skills de projeto valem só ali.

git clone https://github.com/inematds/n8n-maker
cd n8n-maker && claude

MCP n8n-mcp (opcional)

Só necessário para a skill n8n-mcp-tools-expert buscar nodes e publicar workflows.

claude mcp list
Guia de uso · passo a passo

Do clone ao primeiro workflow

Comandos reais. O ponto principal é o passo 3: você descreve o que quer em português e as skills entram sozinhas.

1

Clone o repositório

As skills viajam junto com o repo — nada para instalar além disso.

git clone https://github.com/inematds/n8n-maker
cd n8n-maker
2

Abra o Claude Code dentro da pasta

Skills em .claude/skills/ são de projeto: só carregam quando a sessão roda ali dentro.

claude  # de dentro de ~/projetos/n8n-maker
# confira que apareceram: /skills → n8n-*
3

Peça o workflow em português

Não invoque skill nenhuma. Descreva o objetivo; o Claude escolhe o padrão e monta a estrutura.

# exemplo de pedido
"monta um workflow que recebe um webhook,
 valida o payload e grava no Postgres"

# → n8n-workflow-patterns entra com o padrão de webhook
# → n8n-node-configuration configura Webhook, IF e Postgres
4

Refine expressões e Code nodes

Ao mexer em campo dinâmico ou Code node, as skills de sintaxe e de código assumem.

# expressão em campo do node
{{ $json.body.email }}

# Code node (JavaScript)
const items = $input.all();
return items.map(i => ({ json: { email: i.json.body.email } }));
5

Valide e corrija no laço

Espere 2–3 voltas. A n8n-validation-expert traduz a mensagem, aponta a causa e separa erro real de falso positivo.

# pedido típico
"valida esse workflow e corrige o que aparecer"

# → erros reais: corrigidos
# → falsos positivos: explicados e ignorados
6

Publique na sua instância (opcional)

Com o MCP n8n-mcp conectado, a n8n-mcp-tools-expert cria e atualiza o workflow direto no n8n.

"sobe esse workflow na minha instância do n8n"
7

Quer usar em qualquer projeto?

Faça symlink das pastas para o diretório global de skills — assim continuam versionadas aqui.

ln -s ~/projetos/n8n-maker/skills/n8n-* ~/.claude/skills/
Exemplos

Pedidos que acionam cada skill

Como o roteamento acontece na prática — você fala normal, a skill certa aparece.

“Recebo um webhook do Stripe e quero avisar no Slack”

workflow-patterns (padrão de webhook) → node-configuration (Webhook + Slack) → expression-syntax (montar a mensagem).

“Esse $json está vindo undefined”

expression-syntax mostra o acesso correto ao item e a diferença entre $json, $node e dados de webhook.

“Preciso chamar uma API paginada dentro de um Code node”

code-javascript com $helpers.httpRequest e o laço de paginação; workflow-patterns se virar um fluxo próprio.

“A validação reclamou da estrutura do operador do IF”

validation-expert localiza no catálogo de erros, corrige a estrutura e diz se é caso de falso positivo.
